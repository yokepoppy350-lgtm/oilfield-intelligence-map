# 石油勘探开发智能化地图

纯前端 HTML / CSS / Vanilla JavaScript 课程网站，覆盖13个作业环节、61个教学案例。每例包含专业背景、案例流程与计算演示，案例库支持逐例下载ZIP及上传案例。

## 本地运行

```sh
python -m http.server 8765
```

访问 http://127.0.0.1:8765/ 。无需构建，无业务后端和外部CDN依赖。

## 发布

在GitHub Pages中选择从 main 分支的根目录发布，或使用仓库内的静态资源部署。

## 数据与验证

演示采用固定种子教学合成数据或明确列出的规则记录，具体生成过程、模型及适用边界见每个案例目录的 data-source.md。不代表现场精度或工程施工建议。
