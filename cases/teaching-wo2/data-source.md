# 落物打捞工具智能选型：数据与计算说明

场景 wo2；版本1.0.0；2026-11-04。

## 来源

专业背景与数据条件来自课程附件《石油勘探开发的智能化可能性地图-全网站设计.txt》及原始场景清单；没有下载或暗示已取得现场数据。

在三种合成工具类型中进行可解释的约束选型。

## 合成过程与算法

固定种子 948，线性同余生成器 s=(1664525s+1013904223) mod 2^32。所有扰动由同一控件条件下重新初始化的生成器产生，无时间随机数。

每例三条公开可见的合成候选记录，无隐藏训练集和虚构准确率。

先检查尺寸≤上限且代价≤预算，再评分0.75×(1−|当前特征−案例特征|)+0.25×(1−代价/100)。

落物形态相似性决定检索方向，尺寸上限与预算是先验硬约束；证据链显示候选被排除的原因。

生成公式、默认输入、训练记录或候选记录全部写在demo/index.html的CASE_CONFIG及demo/demo.js中。TeachingCore.run(CASE_CONFIG,输入)返回与界面相同的指标、逐行结果及图形；导出CSV不需要联网。

## 适用边界

教学尺寸不代表工具规格，未考虑鱼顶状态和实际抗拉极限。

模型只在设定的合成关系上评价。留出分数说明本例计算是否复现，不代表真实油田精度；低阈值、强噪声、不可行预算等情况会保留失败结果。
