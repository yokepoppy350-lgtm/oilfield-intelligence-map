# 完井方式智能优选：数据与计算说明

场景 co1；版本1.0.0；2026-11-04。

## 来源

专业背景与数据条件来自课程附件《石油勘探开发的智能化可能性地图-全网站设计.txt》及原始场景清单；没有下载或暗示已取得现场数据。

通过相似案例评分与尺寸/预算规则比较三种教学完井方式。

## 合成过程与算法

固定种子 710，线性同余生成器 s=(1664525s+1013904223) mod 2^32。所有扰动由同一控件条件下重新初始化的生成器产生，无时间随机数。

每例三条公开可见的合成候选记录，无隐藏训练集和虚构准确率。

先检查尺寸≤上限且代价≤预算，再评分0.75×(1−|当前特征−案例特征|)+0.25×(1−代价/100)。

地质相似性提供排序依据，尺寸与代价必须先作为硬约束；高相似度不能补偿无法下入的方案。

生成公式、默认输入、训练记录或候选记录全部写在demo/index.html的CASE_CONFIG及demo/demo.js中。TeachingCore.run(CASE_CONFIG,输入)返回与界面相同的指标、逐行结果及图形；导出CSV不需要联网。
