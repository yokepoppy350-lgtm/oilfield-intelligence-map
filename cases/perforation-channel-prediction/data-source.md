# 射孔孔道形态预测：数据与复现

数据性质：全部为教学合成数据，无现场来源或现场校准。不是行业标准范围。
任务：岩石条件改变后，射孔孔道会有多深、多宽？
输入输出：强度与装药特征 → 穿深；评价：穿深 / mm。
教学设定：轮廓用于说明输入与输出，不反映真实侵彻物理。
生成器与模型：demo/demo.js；案例配置与固定种子235：demo/index.html。

常规任务使用线性同余发生器生成240条归一化样本，编号模5为0的48条留出，其余192条训练；所有特征已按生成器给定的0—1范围归一化，不从测试集估计统计量。近邻模型使用训练集中的7个最近邻，特征间等权欧氏距离。分类标签和回归响应的精确生成公式见demo.js各分支。预测结果不是硬编码指标。

孔道与压裂回归使用[1,x1,x2,x3,x1*x2,x1²,x2²]，正规方程加1e-7对角项求解；测试与训练集均值基线在同一留出集计算MAE。分类使用同一留出集计算混淆矩阵、准确率或二分类指标，与多数类基线对照。图像任务从独立的192条灰度训练样本估计两类灰度中心，在48×36的独立合成井壁图上评价IoU/F1，基线为全判背景。时序任务前60天拟合log(q)关于时间的直线，后30天完整留出；控件只改变评价留出长度，不参与训练。时序基线保持第60天末值。

运行：用标准静态HTTP服务打开demo/index.html；不需要业务后端或外部资源。主站与老师模板均可通过case.json添加本目录。重复运行同一输入得到同样结果。图形属于非比例教学示意，标签规则、相对强度、参数等级和响应指数均未经现场验证。
