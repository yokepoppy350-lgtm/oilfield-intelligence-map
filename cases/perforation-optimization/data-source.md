# 射孔参数优化：数据记录

版本：0.2.0；日期：2026-10-23。

## 性质与概念来源

数据全部为教学合成数据，无现场数据，无现场准确率声明。模型、代价、参数范围未经过工程校准。

- SLB Oilfield Glossary，perforation：https://glossary.slb.com/en/terms/p/perforation 。页面未标注日期，访问2026-10-23。用于核对概念，未复制图片或数据。

## 参数与生成

脚本：demo/demo.js 的 generate()、features()、reference()、cost()。无额外生成脚本，避免原模板自动追加脚本时重复执行。

伪随机数：32位线性同余，seed=234，a=1664525，c=1013904223，模2^32。依次生成240条样本，每条按k、d、相位、l、噪声顺序取随机数。

所有范围均为教学设定，不是行业标准：

| 参数 | 意义 | 范围与分布 |
| --- | --- | --- |
| k | 渗透率，mD | 均匀分布[10,200) |
| d | 孔密，孔/m | 均匀分布[8,24) |
| θ | 相位，度 | 等概率60、90、120 |
| l | 穿深，mm | 均匀分布[200,600) |
| y | 相对响应指数 | 无量纲，下面公式生成 |
| c | 施工代价指数 | 无量纲，下面公式计算 |

缩放 K=k/200，D=d/24，L=l/600，P=cos(θπ/180)。

生成式：y=38+18K+34D+18L−12D²−6L²+8DL+7KL−3P+ε。

ε均匀分布[-1,1)，无额外异常注入。该式为教学设定，不能解释为实际产能规律。

代价：c=8+1.6d+0.06l+相位附加项；60°加5，90°加2，120°加0。

## 划分、处理与模型

按从0开始的样本编号：id mod 5=0的48条为测试，其余192条为训练。随机合成序列没有井别或时间结构，不应照搬此划分到现场时序数据。

使用固定教学范围缩放，不从测试集估计任何参数。特征为[1,K,D,P,L,D²,L²,DL,KL]，训练集上求解最小二乘正规方程，采用主元消元。模型系数只用192条训练数据。均值基线也只用训练数据。

## 复现与指标

通过静态HTTP访问demo/index.html，默认A段k=40mD、预算65。默认对照为12孔/m、90°、300mm。

模型指标：48条测试样本MAE，单位为响应指数；均值基线MAE使用相同测试集。结果由页面实际计算，不写死指标。

搜索孔密{8,12,16,20,24}、相位{60,90,120}、穿深{200,300,400,500,600}，共75组合。按c≤预算筛选，默认选响应最大的可行组合。散点显示全部组合，预算外不可选。代价最低32.8；更低预算会显示无可行解。可导出75个候选的CSV。

孔眼图为一米井段的二维展开示意，不能据此判断真实三维方位、破岩形态或现场增产。模型拟合了已知合成机制，测试误差不能证明现实预测能力。
